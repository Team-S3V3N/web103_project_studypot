# User Stories

## Outline User Roles

- **Student:** A college student who wants to find study partners, join group study sessions, or organize a session for a subject.

## Draft User Stories

1. As a student, I want to browse upcoming study sessions, so that I can find opportunities to study with others.
2. As a student, I want to view the details of a study session, so that I can see its subject, date, time, location, and description before joining.
3. As a student, I want to filter study sessions by subject, so that I can quickly find sessions related to my classes.
4. As a student, I want to sort study sessions by date, so that I can see which sessions are happening soonest.
5. As a student, I want to create a new study session, so that I can invite other students to study with me.
6. As a student, I want to enter a title, subject, date, time, location, and description when creating a session, so that other students know what to expect.
7. As a student, I want to open a form in a modal to create a study session, so that I can add a session without leaving the current page.
8. As a student, I want to edit the details of a session I organized, so that I can correct information or update the plan.
9. As a student, I want to delete a study session I organized, so that sessions that are canceled or no longer needed do not remain listed.
10. As a student, I want to join an existing study session, so that I can participate in group studying.
11. As a student, I want to leave a study session I joined, so that I can update my participation if my plans change.
12. As a student, I want to see who has joined a study session, so that I know how many people will be studying together.
13. As a student, I want to see clear error messages when a form has invalid information, so that I can fix mistakes before submitting.
14. As a student, I want to move between the session dashboard and individual session pages, so that I can explore the app easily.
